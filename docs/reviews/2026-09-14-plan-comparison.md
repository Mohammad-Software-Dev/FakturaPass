# Development plan comparison — 14 September 2026

The original development plan and authoritative contracts define a staged product. The implemented local application completes Release A and now includes the local engineering portions of FP-008 and FP-009. It is not yet the commercial SaaS described by Release C.

Reduced VAT, credit notes, delivery and commercial Release C scope must pass their own documented support gates before being enabled.
